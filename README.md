# 叁合 SANHE

叁合创意工作室网站：三位主理人的内容创意、影像制作、直播运营与 AI 产品实践。

网站发布文件位于 `site/`，无需服务端构建。推送 `main` 后，GitHub Actions 自动部署到 GitHub Pages。

## 更新

修改 `site/` 中对应的页面、内容或媒体文件，提交并推送到 `main`。在仓库的 Actions 页面查看部署结果。

请勿将原始履历文档、未公开素材、访问凭据或工作日志提交到本仓库。

## 素材

工作室人物、项目图片与视频用于本站展示，未经许可不得转载。代码中第三方组件的许可证声明保留在相应文件内。

## 彩蛋记录

老三的发现进度与抽取结果保存在访问者当前浏览器中。更换域名、浏览器或清除网站数据后，该记录不会自动迁移。
